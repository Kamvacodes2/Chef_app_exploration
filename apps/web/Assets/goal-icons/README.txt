CHEFMATE GOAL ICON SET

Files
- SVG: scalable vector icons with transparent backgrounds
- PNG: 512 x 512 true-alpha transparent icons

Default icon colour
- #8B2A26

SVG usage
- The icons use `stroke="currentColor"` and define a default colour on the root SVG.
- When inlining an SVG, remove or override the root `style` value and set CSS `color` to recolour it.

Suggested display sizes
- Desktop cards: 36–48 px
- Mobile cards: 32–40 px
